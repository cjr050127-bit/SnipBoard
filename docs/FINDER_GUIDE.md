# SnipBoard 7.0 找图助手

找图助手默认使用轻量本地条件筛选；需要理解图片内容时，可按自己的需求接入云端或本机视觉模型。程序不捆绑、下载或常驻运行大模型，不建立全库 AI 索引。

## 打开与基本操作

点击工具栏「找图助手」，或按 **Ctrl+K** 打开可停靠面板。输入描述后点击「找图」，或按 **Ctrl+Enter**。也可从「窗口」菜单显示或隐藏面板。

- `找横图，宽度至少 1600`
- `蓝色为主的竖图`
- `人物，不要教程`
- `当前工作组里的横图`

识别出的条件显示在面板中，点击 × 可移除单项。轻量模式会立即更新；模型模式移除条件后需再次点击「用模型找图」，不会因此自动产生调用。勾选「接着上次找图」后，可以说「只留竖图」「再排除教程」继续筛选。「返回原筛选」退出找图结果。

## 默认轻量模式

工作组、已有标签、原图尺寸、方向和比例使用已有图库信息筛选。颜色与明度依据已保存的图像特征，条件阈值显示在面板中。内容词只匹配已有标签、文件名和备注，不能识别未标注图片中的姿态、物体、光照或画风。「红衣」不会被替换成全图红色条件。

只有点击找图、移除条件，或当前结果涉及的图库数据更新时才执行轻量检索。搜索使用共享的单个低优先级后台线程，可停止；连续请求取消旧任务。轻量模式没有模型下载、图片发送、原图分析或常驻 AI 索引。最多展示 200 张结果，同时说明完整匹配数量。

## 自行接入模型

点击「接入模型…」，填写兼容多模态 Chat Completions 的接口地址、模型名和 API Key。云端服务必须使用 HTTPS；本机服务可使用例如 `http://localhost:11434/v1` 或 `http://localhost:1234/v1` 的地址。所选模型和服务必须支持图片输入；SnipBoard 不自动安装或启动本地模型。

API Key 仅保留在本次应用会话的内存中，不写入图库或保存的设置。配置界面说明缩略图发送范围，并让用户选择是否允许发送。配置后切换「大模型视觉筛选」，点击「用模型找图」才发起本次调用。云端调用费用由所选服务决定；使用本机模型时，该服务仍会消耗本机资源。

模型模式先用工作组、明确指定的标签、尺寸等已有条件缩小范围，再分析最近的候选缩略图。说「侧脸」会判断画面内容，没有侧脸标签的图片也可进入候选；说「侧脸标签里的图」才限制到已有标签。

如果本次只有工作组、明确标签、尺寸、比例等本地条件，即使选择模型模式也直接显示本地结果，最多展示 200 张，不调用模型或发送图片。普通「同时满足」由本地筛选确认这些硬条件，模型只判断姿态、物体、光照等画面条件。

跨工作组、明确标签等本地条件与画面条件混合的「或」和排除暂不支持，例如「人物工作组或侧脸」「排除侧脸标签里的逆光图」。程序会在发送图片前报错，并提示拆开查询；纯画面条件的「或」，例如「侧脸或逆光」，可以使用。

默认最多分析 12 张，可调整至最多 40 张，每批 1–4 张；使用缓存缩略图，长边不超过 512 像素。界面显示「已分析 N / 全部候选 M」。未分析图片不被当作不符合；本次候选没有匹配，不代表整个图库没有匹配。建议先选具体工作组或增加明确条件，减小范围。悬停结果缩略图可看模型给出的简短理由。

图库更新不会自动再次调用模型，也不自动重试失败的请求。停止会取消后续批次并忽略旧结果；正在等待网络响应的请求可能直到超时才结束，已送达服务的请求不能撤回。模型判断可能有误，尤其是拼图、小尺寸细节和模糊条件，请核对结果。

## 正式程序与升级

7.0 正式程序沿用默认图库 `%LOCALAPPDATA%\SnipBoard\library` 或已选择的自定义图库，保留 Snipaste 连接、默认置顶查看器和更新功能。正式便携包不附带独立预览的 `preview-library` 或示例图片。

先从旧版菜单或托盘「退出应用」，再完整解压新包并运行 `SnipBoard.exe`，保留旁边的 `_internal` 文件夹。7.0 的内部技术版本号为 7.0.0，正式便携包可从 CNB 或 GitHub 下载；0.6.6 可通过软件内检查更新获取新版。

接口功能验证使用本地模拟响应。真实模型的速度、识别效果和服务兼容性需用户配置后体验；默认模式不依赖模型服务。详细数据处理说明见 [隐私说明](PRIVACY.md)。
