# 隐私与本地数据说明

SnipBoard 0.6.4 是本机图片整理应用。当前应用代码不提供账户、图片上传、遥测或云同步；Qt 本地套接字用于同库单实例通信，不是图片上传接口。

软件启动约 4 秒后默认在后台获取公开的版本信息；可在“设置 → 设置…”关闭自动检查，也可从帮助菜单、查看器右击菜单或托盘手动检查。检查和下载会连接 SnipBoard 官网，失败时尝试本项目在 GitHub 的版本信息或发布包。请求不附带图库、图片、备注、标签、个人文件路径或设备标识；托管服务器仍会接收到正常网络连接的信息（例如 IP 地址）。不提供使用统计或广告追踪。

更新包下载到 `%LOCALAPPDATA%\SnipBoard\downloads\版本号`，下载后核对公开版本信息中的文件大小和 SHA256；取消或失败会清理本次下载的临时文件。程序不自动执行更新包，不覆盖正在运行的 EXE，也不改动图库。可退出程序后自行完整解压并运行新版。

连接发现会查看运行中的 Snipaste 程序路径、相关安装/启动记录、快捷方式及常见存储位置，不进行全盘递归检索。唯一来源会自动连接，多来源供选择。可以跳过连接，仅手动导入图片。

连接后读取指定来源的配置、贴图 PNG、`.sp0` 名称候选和日志；副本、标签、图组名称、原始路径、备注和布局可能保存在 `%LOCALAPPDATA%\SnipBoard\library` 及本机诊断日志中。退出后停止轮询；普通自动同步关闭而当前工作组仍启用时，仍会检查新图。

图片删除是逻辑移除，不会立即抹除本地副本；备份也会包含图片和数据库。请只处理你有权使用的图片，妥善保管图库和备份。公开反馈前清理个人路径、图组名称及截图中的私人内容。

如需彻底清理，先退出程序，确认不再需要图库与备份，再由本人删除相应本地文件；不要误删 Snipaste 的原始目录。
