# 隐私与本地数据说明

SnipBoard 7.0（内部技术版本号 7.0.0）是以本地图库为主的图片整理应用。默认轻量找图不发送图片、不下载或常驻大模型，不提供 SnipBoard 账户、遥测、广告追踪或图库云同步。Qt 本地套接字用于同库单实例通信，不是图片上传接口。7.0 当前仅在本机生成，尚未公开发布。

## 可选视觉模型

用户可以自行配置兼容图片输入的模型接口地址、模型名和 API Key，并明确允许发送候选缩略图。仅填写配置不会发起模型请求；切换「大模型视觉筛选」后，点击「用模型找图」才调用。取消单项条件后需重新点击，图库变化不会自动调用，失败的模型请求不自动重试。

所选服务会接收到本次找图描述及分析的候选缩略图。默认最多 12 张，可调整至最多 40 张，每批 1–4 张；使用本地缓存缩略图，长边不超过 512 像素，不为模型请求读取或上传全分辨率原图，也不自动分析整个图库。缩略图仍可能包含私人内容，请在发送前确认选择的图库范围与接口。发送数量小于全部候选时，未分析图片不代表不符合。

API Key 仅保留在本次应用会话的内存中，不写入图库或保存的设置。云端服务需 HTTPS，本机服务可使用回环地址的 HTTP。SnipBoard 不安装、启动或托管模型；本机模型由用户自行运行，该服务的资源占用和数据处理也需要自行管理。云端 API 的费用、请求记录、保留期限与训练使用政策由所选服务决定，SnipBoard 无法控制第三方收到数据后的处理。

停止操作会阻止后续批次并忽略过期结果。已送达服务的请求不能撤回；正在等待网络响应的调用可能直到该请求的超时才结束。关闭面板或停止本次找图不等于服务端删除已经接收的数据。模型判断存在误差，请核对结果。

## 更新检查与下载

软件启动约 4 秒后默认在后台获取公开的版本信息；可在“设置 → 设置…”关闭自动检查，也可从帮助菜单、查看器右击菜单或托盘手动检查。检查和下载会连接 SnipBoard 在 CNB 的公开项目，失败时尝试本项目在 GitHub 的版本信息或发布包。请求不附带图库、图片、备注、标签、个人文件路径或设备标识；托管服务器仍会接收到正常网络连接的信息（例如 IP 地址）。不提供使用统计或广告追踪。

更新包下载到 `%LOCALAPPDATA%\SnipBoard\downloads\版本号`，下载后核对公开版本信息中的文件大小和 SHA256；取消或失败会清理本次下载的临时文件。程序不自动执行更新包，不覆盖正在运行的 EXE，也不改动图库。可退出程序后自行完整解压并运行新版。

连接发现会查看运行中的 Snipaste 程序路径、相关安装/启动记录、快捷方式及常见存储位置，不进行全盘递归检索。唯一来源会自动连接，多来源供选择。可以跳过连接，仅手动导入图片。

连接后读取指定来源的配置、贴图 PNG、`.sp0` 名称候选和日志；副本、标签、图组名称、原始路径、备注和布局可能保存在 `%LOCALAPPDATA%\SnipBoard\library` 及本机诊断日志中。退出后停止轮询；普通自动同步关闭而当前工作组仍启用时，仍会检查新图。

图片删除是逻辑移除，不会立即抹除本地副本；备份也会包含图片和数据库。请只处理你有权使用的图片，妥善保管图库和备份。公开反馈前清理个人路径、图组名称及截图中的私人内容。

如需彻底清理，先退出程序，确认不再需要图库与备份，再由本人删除相应本地文件；不要误删 Snipaste 的原始目录。
