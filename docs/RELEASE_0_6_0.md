# SnipBoard 0.6.0 Preview：可停靠面板

将原固定侧栏拆分为八个可独立拖动的面板：当前工作组与参考组、标签、色彩、明度、图片比例、图片尺寸、筛选管理、相似推荐。

## 下载与使用

下载 `SnipBoard-0.6.0-Windows-x64.zip`，完整解压后运行 `SnipBoard.exe`，保留 `_internal`，无需 Python。升级前先在旧版菜单或托盘选择“退出应用”，避免同库单实例机制仍打开旧版。

- 拖动标题栏：移动、停靠、浮动或与其他面板组合标签页。
- 双击标题栏：切换浮动与停靠；拖动边界调整尺寸。
- 窗口菜单：勾选显示或隐藏每个面板；关闭按钮只隐藏面板。
- 窗口 → 恢复默认面板布局：找回全部面板，不清除筛选条件。
- Tab：显示或隐藏全部筛选面板。
- 每个图库窗口独立保存布局，正常退出重启后恢复；支持旧窗口状态。

隐藏面板不清除筛选，也不停止工作组自动收集。相似推荐面板可独立缩放并按自身宽度更新两排推荐。

## 验证范围

新增 6 项面板回归覆盖菜单开关、关闭与重开、浮动/停靠/标签页/隐藏状态恢复、多窗口独立、筛选与当前组不受隐藏影响、默认布局恢复、旧/损坏状态兼容，以及推荐面板缩放。完整回归 **114 项通过**（96.077 秒）；打包 EXE 独立图库自检通过，随包 19 个应用模块与源码一致性校验通过。
