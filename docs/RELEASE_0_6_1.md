# SnipBoard 0.6.1 Preview

本版解决图片误加入标签后，无法直接取消单张图片标签的问题。

## 新功能

- 大图底部改为单行标签栏，每个标签右侧带 ×；标签过多时可横向滚动。
- 缩略图、推荐图片和大图右键新增“取消标签”子菜单，列出这张图片的现有标签。
- 操作只解除当前图片与一个标签的关联，不删除图片、标签或其他图片的关联。
- 同时支持手动标签、Snipaste 来源标签和本地导入标签；取消来源标签不会被后续同步恢复，重新拖入可恢复关联。
- 同步刷新标签计数、交叉筛选、多窗口和参考画布；历史导航不会重新显示已取消标签。

## 下载使用

下载 **SnipBoard-0.6.1-Windows-x64.zip**，完整解压后运行 SnipBoard.exe，保留同目录 _internal 文件夹。Windows x64，免费、MIT 开源。

升级前先从菜单或托盘退出旧程序。新版继续使用原本的默认图库；首次打开旧数据库会在图库 backups 目录保存升级前副本，再升级到 schema 6。请勿用旧版直接打开升级后的图库。

## 验证

- 完整回归：120 项测试。
- 新增 6 项专项测试覆盖单图标签移除、重启与同步保持、显式重新加入、旧库迁移备份、多选右键作用域、多窗口/画布刷新及长标签横向滚动。
- Windows 便携包 EXE 自检、打包源码一致性与 ZIP 完整性校验。

仍为 Preview；干净 Windows 环境、多显示器动态 DPI、睡眠恢复和大规模真实图库性能仍需更多实测。
