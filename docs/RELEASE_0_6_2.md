# SnipBoard 0.6.2 Preview

本版修复绘画时参考图查看器落到其他窗口下方的问题，默认启用始终置顶。

## 改进

- 查看器默认保持在其他普通窗口上方，切回绘画软件后仍可查看参考图。
- 右击查看器，在菜单顶部勾选或取消“始终置顶”；查看器获得焦点时可按 **Ctrl+Shift+A** 切换。
- 手动取消后记住选择，下次打开继续使用该设置。旧版普通窗口默认设置首次升级时自动改为置顶；已有的明确置底设置保留。
- 置顶状态意外丢失后自动恢复，不抢占绘画软件的输入焦点。正常置顶时不反复调整窗口顺序；隐藏或最小化后不会自行弹出。

## 下载与升级

下载 **SnipBoard-0.6.2-Windows-x64.zip**，完整解压后运行 `SnipBoard.exe`，保留同目录 `_internal` 文件夹。Windows x64，免费、MIT 开源。

升级前先从菜单或托盘“退出应用”关闭旧程序，再运行新版。新版继续使用原来的默认图库，无需重新导入图片。建议升级前通过“文件 → 备份收藏库”备份。

本版延续 0.6.1 的单图标签取消、0.6.0 的自由停靠面板，以及参考图画布与筛选功能。

## 验证

- 完整回归：123 项测试通过。
- 新增 3 项专项测试覆盖默认置顶、旧设置迁移、实际快捷键切换、右击开关与取消后的设置保存。
- Windows 原生窗口验证覆盖置顶恢复、不抢焦点、取消置顶、隐藏保持、重新显示及最小化恢复。
- Windows 便携包 EXE 自检、打包源码一致性、文件清单与 ZIP 完整性校验；同时提供 ZIP 的 SHA-256 校验文件。

仍为 Preview；干净 Windows 环境、多显示器动态 DPI、睡眠恢复和大规模真实图库性能仍需更多实测。
