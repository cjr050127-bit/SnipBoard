# SnipBoard 0.6.3 Preview

本版将 GitHub 项目页、Windows EXE、软件窗口和托盘图标统一为新版“交错画布”抽象 S 标识，延续 0.6.2 的默认置顶修复。

## 更新

- 使用深墨绿与浅鼠尾草绿的抽象标识替换原图钉图标。
- EXE 内嵌多种尺寸的 Windows 图标，窗口与托盘读取同一份品牌素材。
- 图标随程序打包，移动整个便携版文件夹后也可正常显示。
- 保留默认置顶、右击开关、Ctrl+Shift+A 切换、单图标签取消与自由停靠面板。

## 下载与升级

下载 **SnipBoard-0.6.3-Windows-x64.zip**，完整解压，保留 `SnipBoard.exe` 旁的 `_internal` 文件夹，再运行 EXE。Windows x64，免费、MIT 开源。

升级前先从托盘“退出应用”关闭旧版。新版继续使用原来的默认图库；建议先备份，无需重新导入图片。

已下载的旧 EXE 不会自行改变图标。请运行本次下载的新文件；若旧快捷方式仍显示旧图标，可从新版 EXE 重新创建快捷方式。

## 验证

- 完整回归：123 项测试通过。
- 校验源码运行与打包运行时图标、EXE 内嵌图标，以及随包品牌素材的一致性。
- Windows 便携包 EXE 自检、源码一致性、文件清单与 ZIP 完整性校验；同时提供 SHA-256 校验文件。

仍为 Preview；干净 Windows 环境、多显示器动态 DPI、睡眠恢复和大规模真实图库性能仍需更多实测。
