# SnipBoard 0.6.5 Preview

更新提醒、软件内下载与更稳的官网下载源。

- 启动后后台检查新版，在图片库右下角与托盘提醒；不自动弹窗打断画画。
- 帮助菜单、查看器右击菜单与托盘可查看更新说明并下载。设置中可关闭自动检查，也可跳过某个版本。
- 官网和应用优先使用独立的 R2 下载源，采用 4 MB 分段请求；中断分段可重试，避免部分网络代理截断大文件。
- 显示下载进度、支持取消，完整下载后核对大小与 SHA256，连接失败可使用 GitHub 备用。
- 官网新增两源下载统计和翻牌计数；“第 xx 位使用者”按累计下载次数估算，非独立用户或成功安装数。

## 升级

0.6.4 用户可在“帮助 → 检查更新／下载新版…”取得本版。0.6.3 及更早版本需要先从官网下载一次新版。

便携更新：下载 → 从菜单或托盘退出旧版 → 完整解压到新文件夹 → 运行新版 `SnipBoard.exe`。保留 `_internal` 文件夹。默认图库保存在 `%LOCALAPPDATA%\SnipBoard\library`，更换程序目录不会清空图库；自定义图库继续选择原路径。

官网下载源已实测完整下载并通过 SHA256 校验。实际速度受网络影响，保留 GitHub 备用；应用不自动执行或覆盖运行中的 EXE。
