# SnipBoard 0.6.6 Preview

国内介绍与下载入口迁移到腾讯 CNB，同时将软件内更新接入 CNB。

- 产品介绍、截图、使用手册和 Windows ZIP 使用公开 CNB 项目与 Release 附件提供，无需购买域名或服务器。
- 软件启动后台检查、手动检查和软件内下载优先使用 CNB，GitHub 保留备用。
- CNB 下载使用固定版本链接；允许跳转到 CNB 的 `asset.cnb.cool` 文件服务，继续验证大小、SHA256 和分段范围。
- 保留更新进度、取消、版本跳过和关闭自动检查；本版不改变图库结构。

## 升级

0.6.5 及更早版本没有内置信任新的 CNB 下载域名，国内用户请先从 CNB 手动下载一次 0.6.6；以后可通过本版的软件内更新获取新版本。

下载 → 从菜单或托盘退出旧版 → 完整解压到新文件夹 → 运行新版 `SnipBoard.exe`。保留 `_internal` 文件夹。默认图库位于 `%LOCALAPPDATA%\SnipBoard\library`，更换软件目录不会清空图库；自定义图库继续选择原路径。

## 验证

完整回归 144 项通过，覆盖 CNB 版本与文件名匹配、第三方地址拒绝、签名重定向保留 Range、旧源兼容、下载校验、取消和更新窗口。

## 免费入口的范围

国内入口是 CNB 的公开项目介绍页与版本下载页。原自定义网页继续保留，但不作为国内唯一下载入口。CNB 项目介绍页不能运行原官网的翻牌脚本，公开附件接口当前也未提供可用的实时下载量字段，暂时不显示 CNB 实时下载数或双源总数。

网络可用性和速度仍因地区、运营商而异；发布时核对匿名访问、完整下载及 SHA256。程序不自动执行下载包，不覆盖运行中的 EXE。
