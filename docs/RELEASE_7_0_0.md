# SnipBoard 7.0

日期：2026-10-14。内部技术版本号：7.0.0。正式版本。

## 本版变化

- 修复 Windows 用户目录重定向时导入图片报 WinError 17 的问题：保存图片副本与缩略图时，按暂存文件的真实磁盘路径完成原子替换。JPG 等图片的格式与完整性校验保持不变。
- 新增工具栏「导入文件夹」及「文件 → 导入文件夹…」（Ctrl+Shift+O）：一次导入所选文件夹与子文件夹中的图片，自动添加所选文件夹名称标签并显示该标签组；同名文件夹合并到同一标签，重复图片补上标签并保留原有标签。扫描及导入在后台进行，不监控原文件夹。
- 新增可停靠的找图助手，通过工具栏、Ctrl+K 或「窗口」菜单打开；自然语言条件可逐项移除，支持接着上次筛选与返回原筛选。
- 默认轻量筛选复用现有工作组、标签、尺寸、比例、颜色和明度信息；内容词匹配标签、文件名与备注。共享单个低优先级检索线程，可停止，不常驻加载大模型或自动扫描全库。
- 用户可自行配置兼容图片输入的云端或本机视觉接口。配置、允许发送并点击「用模型找图」后才调用；API Key 仅保留在本次会话内存。
- 视觉筛选默认分析最近的 12 张候选，最多 40 张，每批 1–4 张，使用长边不超过 512 像素的缓存缩略图。显示分析数量与全部候选数，悬停结果显示简短理由。
- 模型模式「侧脸」判断内容并包含未标注候选；「侧脸标签」才限制已有标签。模型模式移除条件需再次点击，图库变化不自动调用，失败请求不自动重试。
- 只有本地硬条件时直接显示本地结果，最多展示 200 张，不调用模型或发送图片；普通「同时满足」由本地确认硬条件，模型仅判断画面内容。本地条件与画面条件混合的「或」和排除暂不支持，发送前提示拆开查询；纯画面条件的「或」可用。
- 正式启动沿用原有图库与设置，不附带预览示例库；保留默认置顶查看器、自由面板、标签取消、CNB 下载及软件内更新。

## 使用与性能边界

轻量模式不能识别未标注的姿态、光照和画风。视觉筛选仅覆盖本次选取的候选，不是全库内容检索；没有匹配不能解释为全库没有匹配。模型判断不是百分之百准确。

停止会阻止后续批次并忽略过期结果，等待中的网络请求可能直到超时才结束；已送达服务的请求无法撤回。本机模型由用户自行运行，也可能占用 CPU、GPU 和内存；云端服务可能收费。默认轻量模式不依赖模型服务。

见 [找图助手说明](FINDER_GUIDE.md)、[使用手册](USER_GUIDE.md) 与 [隐私说明](PRIVACY.md)。

## 下载与升级

退出旧版后完整解压 `SnipBoard-7.0.0-Windows-x64.zip`，保留 `_internal` 文件夹并运行 `SnipBoard.exe`。默认图库路径不变，自定义图库继续选择原路径；建议升级前先备份收藏库。

[CNB 国内下载](https://cnb.cool/snipbroad-jrc/SnipBoard/-/releases/tag/v7.0.0) · [GitHub 备用下载](https://github.com/cjr050127-bit/SnipBoard/releases/tag/v7.0.0)。选择 Windows x64 ZIP，而非自动生成的源码归档；同页提供 SHA-256 校验文件。0.6.6 可在帮助菜单检查更新，0.6.5 及更早版本建议从 CNB 手动下载一次新版。
