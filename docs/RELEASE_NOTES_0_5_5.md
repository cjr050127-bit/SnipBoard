# SnipBoard 0.5.5 Preview

Windows 本地图片库与参考图查看器：整理 Snipaste 已保存贴图或手动导入图片，使用标签、颜色和尺寸筛选，再以紧凑画布组合参考素材。

## 下载与运行

- 普通用户下载 **SnipBoard-0.5.5-Windows-x64.zip**，完整解压后运行 `SnipBoard.exe`；保留 `_internal`，无需安装 Python。
- 首次可连接本机 Snipaste，也可跳过并按 **Ctrl+O** 导入图片。调整查看器窗口后按 **Ctrl+P** 紧凑排列。
- **SnipBoard-0.5.5-Qt-Corresponding-Sources.zip** 为 Qt/PySide/Shiboken 对应库源码，提供给开发者与希望修改依赖库的用户；普通运行不需要下载它。
- `.sha256` 为下载校验值，`VERIFICATION.json` 为发布包检查记录。GitHub 自带的 Source code 是项目源码。

## 本版内容

- 重构紧凑拼版，独立等比缩放、保留图片与旋转角度，改善窗口利用率。
- 默认紧凑间距为 3 px，允许调至 0，与其他排列间距独立。
- 双界面、多窗口图库、拖拽参考组与标签、交叉筛选、本地相似推荐、背景切换、备份恢复。
- 首次 GitHub 公开发布：MIT 授权、产品截图、中文使用手册、隐私和 Snipaste 兼容风险说明，以及依赖许可证与对应源码。

## 验证与边界

发布准备期间 108 项测试通过。公开 ZIP 的程序和运行库与已构建的 0.5.5 保持相同，补充公开说明及许可材料，并重新生成文件清单与 ZIP 校验值。

仍为未签名 Preview；真实跨屏动态 DPI、睡眠恢复、万张图库性能及干净 Windows 环境未完成全面实测。升级前备份图库。关闭窗口仍驻留托盘，请用“退出应用”完全退出。

SnipBoard 是独立项目，与 Snipaste/PureRef 无隶属或官方授权关系。Snipaste 来源只读，但当前会读取 `.sp0` 名称候选与日志，不能把只读等同于零法律风险。详情见仓库文档。
