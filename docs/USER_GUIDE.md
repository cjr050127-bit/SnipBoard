# SnipBoard 0.6.2 使用手册

Windows 本地贴图图片库与参考图查看器。自动同步仅纳入 **Snipaste 贴图图组中的 PNG 图片**；也可手动导入本地图片，不纳入截图历史和 `.sp1` 文件；源文件只读。

## 启动

先从旧版菜单或托盘选择“退出应用”，再启动 `解压目录中的 SnipBoard.exe`。保留同目录 `_internal` 文件夹。旧版 EXE 未覆盖；旧版未退出时，同库单实例机制可能继续唤出旧版窗口。

图片库与黑底查看器可共存，Ctrl+N 新建独立图片库窗口，各窗口筛选和浏览状态独立。

## 维护与恢复

- 编辑 → 恢复已移除的内容：恢复图片、标签和本版开始删除的参考组。恢复参考组不会自动启用当前工作组。旧版已清除的手动标签关联只能恢复名称，界面会标明。
- 文件 → 备份收藏库：完成 SQLite 快照及图片校验后发布 ZIP；目标已存在时拒绝覆盖，中断不会留下以最终文件名命名的半成品。
- 文件 → 从备份恢复到新图库：验证数据库、图片校验值与归档路径后恢复到新文件夹，重建缩略图，完成后可选择打开。不会覆盖正在使用的图库。
- 设置 → 检查图库完整性：检查数据库、缺失／损坏图片和缩略图，详情列出问题路径。
- 设置 → 重建缩略图与索引：重新生成可重建的缓存；原图损坏需要从可信源重新导入或恢复备份。
- 首次无 Snipaste 来源时可直接导入本地图片；已配置来源暂时离线时保留该来源，不自动换到另一实例。

## 导入本地图片

“文件 → 导入图片…”（Ctrl+O），支持多选 PNG、JPG/JPEG、WebP、BMP、TIFF 和 GIF。动图及多页图片取第一帧／页，JPEG 方向信息会应用到导入副本。

- 后台复制到收藏库，原文件不变；重复导入跳过重复内容，失败文件可在结果详情中查看。
- 完成后当前窗口清除筛选并显示“L 本地导入”。其他窗口保留各自筛选并刷新。
- 导入图片支持大图浏览、交叉筛选、相似推荐、手动标签和拖入参考组；手动导入不会自动加入当前工作组。
- 原文件移动或删除后，图库副本仍可查看。仅导入所选文件，不监控原文件夹。

## 作品参考组与标签面板

右上方为作品参考组：

- 拖缩略图到“＋ 拖图片到这里建立参考组”或列表空白处，立即新建参考组；拖到已有组则加入，重复图片不会重复入组。
- 0.4.1 修复了固定排列意外关闭拖动的问题。按住缩略图移动时，约 100×92 逻辑像素的小图跟随鼠标；拖到目标组后松开即入组。多选时显示数量；拖动或取消拖动不会误打开大图，普通单击仍原位放大。
- Ctrl＋单击多选后可整批拖入。双击组名或点“重命名”修改名称，单击组名作为筛选条件。
- 选组后点“★ 当前”，该组突出显示并成为当前工作组；新增贴图自动加入，快捷键优先打开。
- 每 5 秒检查一次已经落盘的贴图。首次扫描建立基线，不把已有图库全部装入；软件关闭期间不实时监控，重启扫描可发现相对上次记录新增的贴图。
- 当前工作组启用时，普通自动同步设置即使关闭，也维持每 5 秒检查。右键参考组栏可“取消当前工作组／停止自动收集”。
- 新来源路径、内容替换或重新出现的贴图视为新增事件，组内按内容去重。手动移出组的图片不会仅因重复扫描再次入组。
- 右键参考组名称 →“删除参考组（保留图片）”。仅移除组、成员关系和该组布局，图片和标签保留；删除当前工作组会停止向其自动收集，各窗口同步刷新。
- 参考组右键可打开查看器、加入或移出当前大图，只改变本应用的组成员，不改变 Snipaste。

右下方为统一标签：

- `S` 是 Snipaste 图组自动标签；`L` 是本地导入集合；`#` 是手动标签。
- 单击图片原位放大，在大图下方输入手动标签，以逗号分隔，点“保存标签”或回车。清空后保存可移除此图的手动标签。
- 同内容图片出现在不同 Snipaste 图组时，共享手动标签。
- 大图下方的“图片标签”栏逐个显示该图片的标签，点击标签右侧“×”即可取消该图片的一个标签；标签多时可横向滚动。
- 缩略图（含推荐区）右击 →“取消标签”→ 选择标签，作用于右击的这一张图，即使当前多选也不会取消其他图片的标签。大图右键同样可用。
- 取消标签只解除图片关联，不删除图片或标签本身；来源标签的取消仅保存在 SnipBoard，自动同步不会恢复。需要重新加入时，将图片拖回该标签。
- 标签勾选默认取交集，也可改为“任一满足”。单击名称只选此标签，并保留其他筛选。
- 标签和参考组均可在黑底查看器中打开，分别保存各自布局。

## 右键移除标签与删除图片

- 右击右下方标签列表中的标签 →“移除此标签（保留图片）”。适用于手动标签、Snipaste 自动图组标签和本地导入集合标签；移除作用于整个图库，不是仅取消当前图片的一个标签。
- 移除手动标签会解除所有图片上的该标签；以后手动重新添加同名标签可再次使用。自动图组标签在本应用中移除，Snipaste 图组及其图片不变，后续同步不会自动恢复标签。
- 缩略图、大图、推荐图和黑底查看器的图片均可右击 →“从图片库删除图片（保留源文件）”。多选后右击所选图片可批量删除。
- 删除按图片内容作用于全库，所有标签、参考组、推荐和窗口都会排除该图片；重复来源中的同一图片一起移除，自动同步不会重新加入。删除为持久的逻辑删除，源文件与本地副本保留，不释放副本磁盘空间；明确重新导入同一图片可恢复它及原有整理关系。
- 移除正在筛选的标签会解除该标签条件，保留其他筛选。大图和已打开的查看器会刷新，前进／后退不会重新显示已删除图片。

## 交叉筛选面板

各类别取交集：**参考组 AND 标签条件 AND 搜索词 AND 色彩 AND 明暗 AND 方向 AND 比例 AND 尺寸**。取消某一类限制不会清除其他类；“清除全部筛选”一次复位。两排推荐默认服从当前完整筛选。

- 连续 HSV 色盘：外圈色相，内方盘饱和度／明度，支持 HEX 输入和 HSV 数值显示。
- 色彩最低占比：目标颜色匹配区域占可见图片的最低比例；色差容差越大，接受的近似色越多。
- 平均明度 L* 上下限：0 至 100，与色盘中的 HSV V 不是同一个量。
- 横图／竖图／近方图；常见比例及自定义宽高比，容差 ±5%。
- 原图最小／最大宽高，0 为不限；查看器旋转和缩放不改变原图元数据。
- 下限高于上限等矛盾条件返回空结果，不会自动忽略任何筛选项。

颜色转换使用 sRGB 与 Lab 色差。占比和明度由缩小采样与量化估算，透明区域按 alpha 处理，不计作黑色。首次升级会后台更新颜色特征。

## 黑底查看器

- Ctrl+Alt+B 优先打开当前工作组；没有当前组时恢复上次标签或参考组。不跟随 Snipaste 当前组。
- Page Up / Page Down 切换标签和参考组，右键提供全部操作。
- **鼠标移至图片右下角自动变为旋转光标，按住左键按拖动方向旋转**；多选时各图绕自身中心转，Shift 吸附到 15°。
- 选中图片左下角用于调整尺寸，拖图片本体改变位置。
- R／Shift+R 转 ±90°，[／] 微调 15°，Ctrl+R 复位；右键可输入角度。Shift＋滚轮旋转，Ctrl＋Shift＋滚轮精调 1°。
- 旋转与排列可撤销、重做、随布局保存，不改写原图。
- 滚轮缩放画布，空格＋左键或中键拖动平移；F 适合窗口。
- 拖黑色空白处移动窗口，Shift＋拖空白处框选；Alt＋左键任意位置移动窗口，Alt＋右键调整窗口大小，边缘和角落也可直接拖。
- 右键窗口菜单有居中、左右半屏、尺寸输入、最大化和全屏；双击空白处最大化／还原。

关闭窗口后保留托盘；通过菜单或托盘“退出应用”完全退出。

## 数据与升级

默认图库：`%LOCALAPPDATA%\SnipBoard\library`。当前数据库格式为 schema 5，升级前在 `backups` 自动保存 SQLite 快照，保留图片、备注和旧布局，保留移除记录并兼容旧标签迁移。不要用旧版操作升级后的数据库；回退需恢复升级前快照。

源图片移除后仍保留独立副本。普通“全部图片”包含当前贴图源成员和本地导入图片，手动标签和作品参考组可继续访问已收藏副本。标签和参考组不写回 Snipaste。

## 构建

```powershell
cd SnipBoard
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-build.txt
.\run.ps1 desktop
.\test.ps1
.\build.ps1 -InstallPyInstaller
```

产物为 `dist\SnipBoard-0.6.2\SnipBoard.exe`，附 SHA-256。默认运行测试和打包 EXE 自检，包括双界面、推荐、标签、工作组自动收集、旋转布局恢复及缩略图拖动启用状态和预览。

## 0.5.1 标签拖放

按住缩略图拖到右下方已有标签，目标行高亮后松开即可加入；Ctrl 多选可批量加入，推荐区缩略图也支持。支持手动标签、Snipaste 自动标签及本地导入标签，已有其他标签不受影响，重复加入不重复计数。自动标签的手动归类仅保存在 SnipBoard，后续来源同步会保留。空白处不接收标签拖放。

首次使用会自动备份旧数据库并升级至格式 5。升级后请继续使用 0.5.1 或更新版本；如需回退，应使用升级前的数据库备份。

## 0.5.2 首次连接

解压完整便携包后运行 SnipBoard.exe，无需安装 Python。首次打开会在后台查找 Snipaste：唯一来源自动连接，多个来源展示数据路径供选择。未找到时，请先启动 Snipaste、保存贴图后重新查找；也可选择 Snipaste.exe、config.ini 或数据文件夹。选择“暂时跳过”后可直接导入本地图片，稍后通过“文件 → 连接 Snipaste…”重新连接。

自动发现覆盖运行中的便携版、微软商店版、桌面及开始菜单中的 Snipaste 快捷方式、安装和启动记录、常见便携位置。支持 config.ini 的 General/history_dir；识别相对路径、环境变量和路径中的空格。不进行全盘递归扫描，未运行且放在特殊位置、没有快捷方式的版本仍需手动选择。来源暂时离线时保留本地图片与原连接，不自动替换。

## 0.5.3 查看器背景

参考图查看器右键 → 背景：黑色、白色、灰色、透明。自动记住选择。透明时图片保持清晰，拖动背景可移动窗口、拖边角可缩放窗口，操作期间显示浅蓝色发光边缘，松手后短暂提示再消失。Esc 可取消窗口操作。


## 0.5.4 按窗口紧凑排列

先调整查看器窗口大小，再按 Ctrl+P 或右键选择“紧凑排列”。按当前窗口重新排列整个集合，分别等比缩放图片，综合减少留白与保持显示面积大致均衡；保留完整内容和已有旋转角度。可撤销，并保存布局。仅选中部分图片时，此命令仍处理整个集合，其他对齐与排列命令沿用原选择范围。

计算在后台进行，搜索预算约 1.2 秒；拖动图片、切组或取消后，旧结果不会覆盖新操作。窗口尺寸改变后请再次按 Ctrl+P。右键“外观设置…”可调整间距，紧凑排列使用屏幕逻辑像素间距。比例很极端或图片经过旋转时仍会留下空白，不保证数学上的最优解。算法依据及测试见 0.5.4 更新记录（历史开发记录）。


## 0.5.5 紧凑拼版重构

Ctrl+P／右键“紧凑排列”使用当前窗口大小，重新拼接整个集合的图片。每张图片独立等比缩放，保留完整内容与旋转角度，兼顾显示大小均衡与减少空洞。已有保存布局不会自动覆盖，请执行一次紧凑排列应用新算法。

紧凑排列默认间距由 18 改为 3 个逻辑像素，窗口内边距为 3 个逻辑像素。右键“外观设置…”可单独修改紧凑排列间距，设为 0 可使图片相接；确认后立即重新排列。该设置与按名称等其他排列的间距独立，升级旧图库也默认使用新的窄间距。

缩小间距无法填满所有由比例差异产生的空白，因此同时重构了图片组合方式。仍保持不裁切、不变形，极端长宽比和斜向旋转可能留下空间。详细算法、实际对比与验收见 0.5.5 更新记录（历史开发记录）。

## 0.6.0 可停靠面板

八个面板：当前工作组与参考组、标签、色彩筛选、明度筛选、图片比例筛选、图片尺寸筛选、筛选管理、相似推荐。

按住标题栏拖动可自由改变位置，停靠到主窗口四边、上下/左右组合、与其他面板叠成标签页，或拖出为浮动窗口。双击标题栏切换浮动与停靠，拖动边界调整面板尺寸。初始布局的明度、图片比例、图片尺寸、筛选管理共用一组标签页，可单独拖出。

“窗口”菜单直接列出各面板的勾选开关；点面板右上角 × 隐藏后，从这里重新显示。“窗口 → 恢复默认面板布局”恢复默认排列及所有面板显示，不清除筛选或改变工作组。Tab 统一显示/隐藏五个筛选面板。

隐藏筛选面板后原条件仍有效，可通过“编辑 → 清除筛选”清除；隐藏当前工作组面板不会停止自动收集，需在参考组右键菜单取消当前工作组。相似推荐现在是独立面板，在图库中选择图片后更新。

各图库窗口独立保存面板停靠位置、浮动状态、标签页组合、尺寸及显隐。正常退出后随既有窗口状态保存，重启恢复；旧版状态没有面板信息时使用默认排列。浮动面板位于已断开的显示器之外时会移回可用屏幕。

## 查看器始终置顶

参考图查看器默认始终置顶，切换到绘画软件时仍保持可见。右击查看器，在菜单第一项“始终置顶”中勾选或取消；查看器获得键盘焦点时，也可按 **Ctrl+Shift+A** 切换。

取消后恢复普通窗口层级，该选择会记住；重新置顶时再勾选即可。升级后旧版默认的普通层级会一次性改为置顶，显式设为底层的配置保留。程序仅恢复丢失的置顶状态，不抢占绘画软件焦点，也不会重新打开已关闭或最小化的查看器。
